# DevPortfolio - Personal Portfolio Website

This is a personal portfolio website built with Next.js in Firebase Studio. It's designed to showcase projects, skills, and professional experience in a modern, responsive, and multilingual interface.

## Key Features

- **Project Showcase**: A dedicated section to display work with detailed descriptions, tech stacks, and links to GitHub repositories.
- **About Me**: A comprehensive page detailing professional background, skills, work experience, and education.
- **Multi-language Support**: Fully internationalized for English and Spanish using Next.js's App Router and `i18n`.
- **Contact Form**: A functional contact form built with Next.js Server Actions for secure and seamless communication.
- **Responsive Design**: The entire site is optimized for a great user experience across all devices.
- **SEO Optimized**: Includes dynamic metadata generation and a `sitemap.xml` for better search engine visibility.

## Tech Stack

This project is built using a modern and robust set of technologies:

- **Framework**: [Next.js](https://nextjs.org/) (using the App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [ShadCN UI](https://ui.shadcn.com/) for a modular and accessible component library.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for smooth page transitions.
- **Forms**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/) for robust form handling and validation.
- **AI Integration**: [Genkit](https://firebase.google.com/docs/genkit) for generative AI capabilities.
- **Testing**: [Jest](https://jestjs.io/) and [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/) for ensuring code quality.
